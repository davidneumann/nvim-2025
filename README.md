# Requirements
This config was made on a nixos system, as such there is no Mason. You will need to install these tools yourself.

## Lua
### LSP
Binary: `lua-language-server`
Nix package: [lua-language-server](https://github.com/NixOS/nixpkgs/blob/nixos-unstable/pkgs/by-name/lu/lua-language-server/package.nix#L133)

## Typescript
### LSP
Binary: `typescript-language-server`
Nix package: [typescript](https://github.com/NixOS/nixpkgs/blob/nixos-unstable/pkgs/by-name/ty/typescript/package.nix#L33)

### DAP
Binary: `js-debug`
Nix package: [vscode-js-debug](https://github.com/NixOS/nixpkgs/blob/nixos-unstable/pkgs/by-name/vs/vscode-js-debug/package.nix#L85)
